# 🐚 Submarine — подводный сканер 360° 🐚

> *Сканируй пространство, строй карту и исследуй подводный мир!*

Добро пожаловать в проект **Submarine** — мой первый университетский проект в МИИГАИК. Это автономный аппарат, который сканирует окружающее пространство на 360° с помощью ультразвукового датчика и строит двумерную карту в реальном времени. Всё управляется через Arduino, а данные передаются на ПК для визуализации.

## ✨ Что внутри

- **Сканер 360°** — ультразвуковой сонар на сервоприводе или шаговом двигателе.
- **Построение 2D-карты** — данные обрабатываются и визуализируются на ПК.
- **Два датчика** — для более точного измерения расстояний (с усреднением).
- **Управление через Serial** — команды `START`, `STOP`, `RESET` для запуска и остановки сканирования.
- **Код на Arduino** — оптимизирован для работы с библиотеками `NewPing` и `Servo`.

## 🚀 Как запустить

1. **Клонируй репозиторий**

```bash
git clone https://github.com/unidari/Submarine.git
cd Submarine
Открой проект в Arduino IDE

Загрузи скетч Arduino/sketch_jul12a/sketch_jul12a.ino.

Установи необходимые библиотеки:

NewPing — для работы с ультразвуковым датчиком.

Servo — для управления сервоприводом.

Подключи оборудование

Подключи Arduino к ПК через USB.

Собери схему согласно пинам в коде (см. раздел «Схема подключения»).

Запусти монитор порта

Открой монитор порта в Arduino IDE (скорость 9600).

Отправь команду START — и начнётся сканирование!

🧩 Схема подключения
Компонент	Пин Arduino
Trigger (датчик 1)	10
Echo (датчик 1)	12
Trigger (датчик 2)	7
Echo (датчик 2)	5
Сервопривод	9
💡 Все пины можно изменить в коде, если нужно.

🎮 Как это работает
Сканирование — сервопривод поворачивается от 0 до 180 градусов.

Измерение — на каждом угле датчики измеряют расстояние (с усреднением для точности).

Передача данных — угол и расстояние отправляются в Serial в формате:

text
угол,расстояние
угол+180,расстояние
Визуализация — данные можно принимать на ПК и строить 2D-карту (например, в Python или Processing).
